# Excalicap 项目文件生命周期设计

## 目标

在 Excalidraw 左上角主菜单中补齐“新建项目、打开项目、保存、另存为”，让用户能够把当前画板明确保存到本地 `.excalidraw` 文件。

## 已确认交互

- 不注册 `Cmd+S`、`Cmd+N`、`Cmd+O`、`Cmd+Shift+S` 或对应的 `Ctrl` 快捷键，避免与浏览器和编辑器快捷键冲突。
- 文件操作只从左上角主菜单触发。
- “打开项目”绑定用户选择的本地文件；之后“保存”原地写回该文件。
- 未绑定文件时点击“保存”等同于“另存为”。
- “另存为”始终让用户重新选择文件。
- “新建项目”创建一个符合当前输出画幅的空白、锁定 Slide，并解除旧文件绑定。
- 新建前若当前内容尚未写入绑定文件，先请求用户确认。
- IndexedDB 自动保存继续作为浏览器草稿恢复机制，不代表已经写入本地文件。
- 不支持 File System Access API 时，“打开”使用文件选择控件，“保存”降级为浏览器下载；降级模式不能原地覆盖文件。

## 文件状态

应用在运行期间维护：

- 当前绑定的文件句柄（如有）。
- 当前绑定文件的名称（如有）。
- 当前画布是否相对最近一次文件保存发生变化。

文件句柄仅保存在当前页面会话中。刷新后浏览器可以恢复 IndexedDB 草稿，但第一次手动保存仍需要重新选择文件，避免持久化权限带来的额外授权复杂度。

## 数据格式

保存使用 Excalidraw 官方 `serializeAsJSON(..., "local")` 输出，确保生成标准 `.excalidraw` 文件并完整包含 elements、appState 与 files。

打开使用 Excalidraw 官方 `loadFromBlob` 解析和恢复，再执行 Excalicap 已有的 Slide 尺寸、位置、锁定及层级归一化。

## 错误与取消

- 用户取消打开、保存或新建确认时，不改变当前画布、绑定文件和文件脏状态。
- 解析失败、读取失败或写入失败时保留当前画布，并显示错误提示。
- 只有写入成功后才更新绑定文件和“已保存到文件”状态。

## 非目标

- 不持久化文件系统权限。
- 不增加本地后端服务。
- 不改变录制、提词器、素材库或视频下载流程。
- 不新增任何项目级键盘快捷键。
